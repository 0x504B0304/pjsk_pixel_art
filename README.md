# PJSK 拼豆绘制

独立 Android 应用，用于 `com.hermes.mk.bilibili` 6.4.0 的「线上拼豆手作」编辑页。导入图片后生成 24 x 24 图案，按游戏实测的 47 色与橡皮擦绘制。与 MAA 没有运行时依赖，不读取或修改游戏文件；ADB 仅用于开发安装。

首次使用需在系统设置中手动开启本应用的无障碍服务。打开拼豆编辑页，回到本应用选图、调整预览，再点「开始绘制并保存」；应用会切回游戏，自动定位网格、色板、保存图标。可用游戏画面左上角的「停止」悬浮按钮中止。默认将白色映射为空白并擦除旧颜色，开启「白色也上色」则使用 H2。游戏要求至少 20 格上色，不足时应用不会开始绘制。

调色原图和 24×24 拼豆结果并排预览。亮度、对比度、饱和度、色温、色相、高光、阴影可调整，修改后先对原图采样点调色，再重新拟合到游戏色板；「重置调色」恢复中性值。调色只更新预览，不会自动修改游戏画布。

「在游戏中悬浮控制」会切回游戏并显示可拖动的控制面板；可在游戏上直接调色、查看预览、开始绘制，也可收起为小按钮。绘制时面板自动隐藏，只保留停止按钮；结束后可重新展开。悬浮窗复用无障碍覆盖层授权，无需另授系统悬浮窗权限。选图会短暂打开系统文件选择器，完成或取消后返回游戏。关闭悬浮控制不会停止已开始的绘制。

定位不依赖 16:9 固定坐标：从截图检测 27 条横纵等距网格线、三个色板颜色锚点及保存图标，任何一项不匹配就停止。已在 1280×720 和真实 1024×768 画面验证。当前仅支持该版本的游戏界面；界面更新后需更新参考颜色/模板。逐格复核通过后才点击「保存完成」，并检查屏幕顶部的成功提示；未能确认时只报告状态，不点击「提交审核」。绘制前、复核后、保存后的真实截图保存在设备 `Pictures/PJSKBeadPainter`。

图像转换算法移植自 MaaAssistantArknights `PixelPaintHelper`，遵循 AGPL-3.0；见 `LICENSE` 和 `NOTICE`。

使用 JDK 17、Android SDK 36 构建并运行单元测试：`gradlew.bat assembleDebug testDebugUnitTest`。可安装 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

`connectedDebugAndroidTest` 中的 `GameVisionTest` 使用截图样本验证识别。其余实机测试会操作游戏画布或修改设备无障碍设置，默认不运行；仅在专用测试画布上通过对应的 `enableLiveCapture`、`enablePaletteTouch`、`enableStopRestore` 或 `enableLiveSave` instrumentation 参数显式启用。不要在已有作品的编辑页运行这些测试。
